Data Mining

คือกระบวนการค้นพบความรู้และรูปแบบที่ซ่อนอยู่ภายในข้อมูล

เป็นการดึงเอาข้อมูลหรือแพทเทิร์นที่มีประโยชน์ออกมาจากข้อมูลจำนวนมหาศาล

Data Mining ในบริบทของ Business Intelligence

ลำดับขั้นทั่วไป:
Data Source → การเตรียมข้อมูล/การผสานข้อมูล, Data Warehouse → การสำรวจข้อมูล → การทำเหมืองข้อมูล → การนำเสนอผลลัพธ์ → การตัดสินใจ

ประเภทของข้อมูลที่สามารถนำมาทำ Data Mining ได้

  1.ข้อมูลในฐานข้อมูล (Database)
  
  2.ข้อมูลในคลังข้อมูล (Data Warehouse)
  
  3.ข้อมูลธุรกรรม (Transactional data)
  
  4.ข้อมูลแบบสตรีม (Stream data)
  
  5.ข้อมูลเชิงพื้นที่และเวลา (Spatiotemporal)
  
  6.ข้อมูลอนุกรมเวลา (Time-Series)
  
  7.ข้อมูลลำดับเหตุการณ์ (Sequence data)
  
  8.ข้อความและข้อมูลจากเว็บ (Text & Web)
  
  9.ข้อมูลมัลติมีเดีย (Multimedia)
  
  10.กราฟ เครือข่ายสังคม และเครือข่ายข้อมูล (Graphs & Social Networks)

1. บทนำสู่เหมืองข้อมูล (Introduction to Data Mining)

นิยาม: คือกระบวนการสกัดเอาความรู้หรือแพทเทิร์นที่น่าสนใจ (ไม่ชัดแจ้งมาก่อน, ไม่เคยรู้มาก่อน และมีประโยชน์) จากข้อมูลจำนวนมหาศาล
ทำไมต้องทำ Data Mining: เนื่องจากข้อมูลเติบโตแบบก้าวกระโดดจากระดับ Terabytes สู่ Petabytes ทำให้เราอยู่ในสภาวะ "ท่วมท้นด้วยข้อมูล แต่ขาดแคลนความรู้"

กระบวนการ KDD (Knowledge Discovery from Data): ประกอบด้วยขั้นตอนหลักคือ การทำความสะอาดข้อมูล (Cleaning), การรวมข้อมูล (Integration), การเลือกและแปลงข้อมูล (Selection & Transformation), การทำเหมืองข้อมูล (Data Mining), การประเมินผล (Evaluation) และการนำเสนอปัญญา (Presentation)

ศาสตร์ที่เกี่ยวข้อง: เป็นจุดร่วมของหลายสาขา ได้แก่ สถิติ, Machine Learning, เทคโนโลยีฐานข้อมูล, และการประมวลผลประสิทธิภาพสูง

3. การทำความรู้จักกับข้อมูล (Getting to Know Your Data)
   
ประเภทของแอตทริบิวต์ (Attribute Types):

Nominal: ชื่อหรือหมวดหมู่ (เช่น สีผม, รหัสไปรษณีย์)

Binary: มี 2 สถานะ (เช่น ชาย/หญิง, บวก/ลบ)

Ordinal: มีลำดับที่ชัดเจนแต่บอกระยะห่างไม่ได้ (เช่น เกรด A-F, ขนาด S/M/L)

Numeric: เชิงปริมาณ แบ่งเป็น Interval (ไม่มีศูนย์แท้ เช่น อุณหภูมิ C) และ Ratio (มีศูนย์แท้ เช่น รายได้, อุณหภูมิ Kelvin)

การวัดค่าทางสถิติ: ใช้ค่ากลาง (Mean, Median, Mode) เพื่อดูแนวโน้ม และใช้ค่าการกระจาย (Variance, Standard Deviation, IQR) เพื่อดูความแปรปรวนของข้อมูล

การวัดความคล้าย (Similarity/Dissimilarity): ใช้ระยะทางต่างๆ เช่น Euclidean, Manhattan หรือ Cosine similarity สำหรับข้อมูลเวกเตอร์

5. การเตรียมข้อมูล (Data Preprocessing)
   
ปัญหาคุณภาพข้อมูล: ข้อมูลในโลกจริงมัก "Dirty" เช่น ไม่สมบูรณ์ (Missing), มีสัญญาณรบกวน (Noisy), หรือไม่สอดคล้องกัน (Inconsistent)
การจัดการข้อมูล:

Data Cleaning: เติมค่าว่าง จัดการ Noise ด้วยการทำ Binning หรือ Regression

Data Integration: รวมข้อมูลจากหลายแหล่งและจัดการปัญหาชื่อแอตทริบิวต์ซ้ำซ้อน

Data Reduction: ลดมิติของข้อมูล (Dimensionality Reduction) เช่น วิธี PCA หรือการเลือกเฉพาะแอตทริบิวต์ที่สำคัญ เพื่อให้ประมวลผลได้เร็วขึ้น

7. การหาแพทเทิร์นที่เกิดขึ้นบ่อย (Frequent Patterns)
   
แนวคิด: ค้นหาไอเทมที่มักจะปรากฏร่วมกัน (เช่น คนซื้อผ้าอ้อมมักซื้อเบียร์คู่กัน)

เกณฑ์การวัด: ใช้ค่า Support (ความถี่) และ Confidence (ความน่าจะเป็นแบบเงื่อนไข)

อัลกอริทึมหลัก: Apriori (ใช้การตัดขอบเขตตามกฎ Downward Closure) และ FP-Growth (ใช้โครงสร้าง FP-tree ทำให้ไม่ต้องสร้าง Candidate และทำงานได้เร็วขึ้น)

การประเมิน: ใช้ค่า Lift หรือ Kulczynski เพื่อตรวจสอบว่าความสัมพันธ์นั้นเป็นเหตุเป็นผลกันจริงหรือไม่ (โดยเฉพาะเมื่อมีข้อมูลประเภท Null เป็นจำนวนมาก)

9. การจำแนกประเภทข้อมูล (Classification)
    
ลักษณะงาน: เป็นการเรียนรู้แบบมีผู้สอน (Supervised Learning) เพื่อสร้างโมเดลทำนายหมวดหมู่ (Label)

เทคนิคสำคัญ:
Decision Tree: แบ่งข้อมูลตามลำดับชั้นโดยใช้ค่า Information Gain หรือ Gini Index

Bayes Classification: ใช้ทฤษฎีความน่าจะเป็น (Naive Bayes)

Linear Classifier: เช่น Logistic Regression และ SVM (ค้นหาเส้นแบ่งที่มี Margin กว้างที่สุด)

Neural Networks & Deep Learning: จำลองการทำงานของสมองมนุษย์ (เช่น CNN สำหรับงานด้านภาพ, RNN สำหรับข้อมูลลำดับเวลา)

การวัดผล: ใช้ Confusion Matrix เพื่อคำนวณ Accuracy, Precision, Recall และ F-measure

11. การจัดกลุ่มข้อมูล (Cluster Analysis)
    
ลักษณะงาน: เป็นการเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning) เพื่อแบ่งกลุ่มข้อมูลที่ "คล้ายกัน" ให้อยู่กลุ่มเดียวกัน

วิธีการสำคัญ:

Partitioning: เช่น K-Means (แบ่งตามค่าเฉลี่ย) และ K-Medoids (ใช้จุดจริงในข้อมูล ลดผลกระทบจาก Outliers)

Hierarchical: สร้างลำดับชั้นของกลุ่ม เช่น AGNES (รวมกลุ่ม) และ DIANA (แบ่งกลุ่ม)

Density-Based: เช่น DBSCAN สามารถหากลุ่มที่มีรูปทรงอิสระและจัดการ Noise ได้ดี

การประเมินคุณภาพ: ใช้เกณฑ์ภายนอก (เทียบกับความจริง) หรือเกณฑ์ภายใน (เช่น Silhouette Coefficient เพื่อดูความหนาแน่นและการแยกจากกันของกลุ่ม)
